# オフトレカイセキ プライバシーポリシー

最終更新日: 2026年7月20日

## 1. 収集する情報

オフトレカイセキ（以下「本アプリ」）は、個人情報、利用履歴、端末識別子、広告識別子、位置情報、解析データその他の利用データを収集しません。アカウント登録機能、広告、アクセス解析、外部サーバーはありません。

## 2. 映像データ

本アプリで撮影した映像およびユーザーが端末から取り込んだ映像は、比較処理に必要な画像キャッシュを含め、ユーザーの端末内だけに保存されます。ギャラリー自動保存を有効にしている場合、撮影した映像のコピーを端末の「Movies/オフトレカイセキ」にも保存します。取り込んだ映像を重複してギャラリーへ保存することはありません。本アプリがこれらを開発者その他の第三者へ送信することはありません。

## 3. ネットワーク通信

本アプリのリリース版はネットワーク通信を行いません。リリース版にはインターネットアクセス権限を含めません。

## 4. 端末機能と権限

本アプリは動画撮影のためにカメラ権限を使用します。カメラ権限を、撮影以外の目的には使用しません。

端末内の動画を取り込む際はAndroidのシステム選択画面（Photo Picker）を使用します。ユーザーが選択した動画だけを本アプリ内へコピーします。

## 5. 第三者提供

本アプリは情報を収集しないため、個人情報や利用データの第三者提供を行いません。

## 6. データの削除

ユーザーは本アプリ内でクリップを削除できます。アプリ内のクリップを削除しても、ギャラリーへ保存済みのコピーはユーザーの資産として残り、削除されません。アプリをアンインストールすると本アプリ専用の端末内保存領域にあるデータは削除されますが、ギャラリーのコピーは残ります。ギャラリーのコピーは端末のフォトアプリ等から削除できます。端末やOSのバックアップ機能による複製については、各サービスの設定とポリシーをご確認ください。

## 7. 改定

本ポリシーを改定する場合は、公開ページ上で改定日と内容を案内します。
