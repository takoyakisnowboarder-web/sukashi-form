## 実機での動作確認（Pixel 8）

実機: Pixel 8（Android 16、端末ID `3C041FDJH0038Z`）、debug APK

1. **モック5画面との照合: 成功。** 撮影、範囲指定、比較通常、設定シート、位置合わせを照合した。差異は後述する。
2. **オーバーフロー: 成功。** 撮影、範囲指定、比較の透過・分割、未同期、設定シート、位置合わせを確認し、縞は出なかった。対象語でlogcatも確認し、RenderFlex overflowとFATAL EXCEPTIONは0件だった。
3. **SafeArea: 成功。** 最下部の撮影操作、範囲指定ボタン、比較リモコン、位置合わせ完了ボタンがナビゲーションバーと重ならなかった。
4. **ギャラリー保存: 成功。** ON録画で `Movies/スカシフォーム/SukashiForm_*.mp4` がMediaStoreに作られ、Googleフォトの動画ビューアで開けた。OFF録画では件数が増えなかった。アプリ内の元クリップ削除後もMediaStore行とGoogleフォト側コピーが残った。
5. **音量キー: 一部制約付きで成功。** 上キー長押しで1回だけ録画開始し、約3秒後も録画中だったため多重発火なし。下キーで停止した。通常画面では録画処理が発火せず、実装上もイベントを `super.dispatchKeyEvent` へ渡すことを確認した。ただし端末の音楽ストリームがシステム側でミュート固定され、ADB注入キーによる音量値の増減は数値確認できなかった。Bluetoothリモコンは未所持のため未実施。
6. **比較操作: 成功。** 大型の1コマ戻る・再生/一時停止・1コマ進む、ループ、0.25/0.5/1.0倍、透過を操作した。シート開閉後も位置・変換を維持した。
7. **位置合わせ: 成功。** 分割で下側Bを直接ドラッグし、透過ではB操作、リセット、完了を確認した。永続化JSONに変換値が保存され、アプリ強制終了・再起動後に同じペアを開けることを確認した。
8. **説明: 成功。** 比較範囲の「比較範囲について」と比較画面の「比較画面の使い方」が表示された。
9. **閉じ方: 成功。** シート表示中の戻る、位置合わせ中の戻る、録画中の戻るを実行し、クラッシュしなかった。録画中の戻るではライブラリへ戻った。

## モックとの差異

- Pixel 8の横幅では、右上の「格子」と「ギャラリー ON/OFF」を同じ行に置くと撮影映像や閉じるボタンと競合するため、右上で縦に並べた。機能の近接性と押下領域を優先した。
- 分割モードの設定シートには、フェーズ4bまでの分割方向切替を残した。モック外の新機能ではなく、既存機能を失わないための維持である。
- 範囲プレビューのフレーム準備中は進捗表示を出す。準備完了後の配置はモックに合わせた。

## プライバシーポリシー修正案

## 実行できなかった項目と理由

- Bluetooth自撮りリモコン実機: リモコンが手元にないため。端末の音量上下キー経路は実施した。
- 通常画面での音量値の数値増減: Pixel 8の音楽ストリームがシステム側でミュート固定され、ADBの音量設定も反映されなかったため。アプリ側で捕捉が無効になり録画通知が起きないことは確認した。
- 最終release AABとrelease実機確認: オーナーの署名鍵が未設定のため。R8・リソース処理後、既定の日本語案内で停止した。

## 設計上の判断 / 逸脱・迷った点

- ギャラリー保存先はカメラロールを占有しにくく、アプリ名で見つけやすい `Movies/スカシフォーム` を選んだ。
- ライブラリ保存完了後にだけギャラリーコピーを試みる。ギャラリー側の例外は警告に留め、主データを失敗扱いにしない。
- 取り込んだ動画はギャラリー保存対象にしない。撮影完了経路だけが保存処理を呼ぶ構造にした。
- API 28では新しいストレージ権限を追加せず、ギャラリー設定を表示しない。
- `ComparisonController`、フレーム展開、同期計算、既存永続化形式は変更していない。
- release用リソースの権限確認結果は次のとおり。後半2行はAndroidXのアプリ固有receiver保護権限で、アプリが要求する通常権限ではない。

  ```text
  package: com.sukashiform.app
  uses-permission: name='android.permission.CAMERA'
  permission: com.sukashiform.app.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION
  uses-permission: name='com.sukashiform.app.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION'
  ```
